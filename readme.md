Nombre del proyecto: Los agujeros negros.

Descripcion breve: La pagina tiene la finalidad de tratar que las personas puedan "entender"y mas o menos poder responder algunas preguntas relacionadas como por ej: ¿que es?,¿que pasa si se acercan?,¿de donde salen?,¿existen?,etc, y tratar de que a estas personas les de curiosidad y compartir mi fasinacion por estos agujeros(o por la pelicula que tambien esta muy buena)

Nombre del estudiante:Facundo Maldonado.

Instrucciones baiscas de uso: La pagina es muy intuitiva cuenta con un encabezado para poder navegar por las distintas paginas,la seccion de imagenes cuenta con botones para poder inr cambiando las mismas,la seccion interestellar tiene musica que bajando hasta el final de esa pagina se puede parar ,bajar o subir el volumen(esta seteada a 30%), y en la seccion contacto se encuentra el formulario para mandar un mensaje se tiene que ingresar un nombre mayor a 3 letras el correo tiene que tener un "@"en un lugar especifico y el telefono solo acepta numero del 0 al 9 y esta truncado a 15 numeros
